## Directory Structure

```
OIM3641-classwork-charles/
├── README.md               # Overview of the repo (this file)
├── pyproject.toml          # Project config and dependencies
├── .gitignore              # Files and folders Git should ignore
├── main.py                 # Entry point
│
├── in-class-activities/    # Weekly in-class exercises
│   ├── activity-01/
│   ├── activity-02/
│   └── ...
│
├── homework/               # Individual assignments
│   ├── hw-01/
│   └── ...
│
├── projects/               # Larger project work and milestones
│   └── project-name/
│       ├── data/           # Raw and cleaned datasets
│       ├── notebooks/      # Jupyter notebooks for exploration
│       └── src/            # Reusable scripts and functions
│
└── data/                   # Shared datasets used across assignments
```

Each assignment folder contains its own notebook or script plus any data it needs, so every piece of work can run on its own.

## Install Instructions

**1. Clone the repository**

```
git clone https://github.com/732198/OIM3641-classwork-charles.git
cd OIM3641-classwork-charles
```

**2. Create and activate a virtual environment**

```
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

**3. Install dependencies**

```
pip install -e .
```

**4. Run the code**

```
# Open notebooks
jupyter notebook

# Run a Python script
python path/to/script.py
```
